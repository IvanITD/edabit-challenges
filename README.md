## How this repo is organized

Each challenge is its own folder. Open the folder for the solution and a short note about it.

| File | What you'll find |
| --- | --- |
| `solve.js` | The solution |
| `README.md` | The challenge name, an Edabit link, and one line on what the code does |

```text
JavaScript/
  01-How Edabit Works/
    solve.js
    README.md
```
